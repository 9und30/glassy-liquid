# Security policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 0.1.x   | Yes       |

## Reporting a vulnerability

Report security vulnerabilities privately through GitHub Security Advisories:

<https://github.com/9und30/glassy-liquid/security/advisories/new>

Please do not open a public issue, pull request, or discussion for a security report.

Include the version you tested, what the impact is, and a reproduction if you have one. The maintainer will acknowledge the report, work on a fix, and credit you in the changelog unless you ask not to be named.

If you are unsure whether something is a vulnerability, use the private advisory anyway.
