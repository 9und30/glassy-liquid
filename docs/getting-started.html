Guide

Start with one import.

The custom elements work in plain HTML. React, Vue, and Svelte wrap those same elements, with the same names and the same events.

Install

npm install glassy-liquid

React, Vue, and Svelte are optional peer dependencies. Install the one you already use. Nothing else is required: no WebGPU, no runtime dependencies.

First surface

If you also write raw <glass-*> tags in a Vue template, mark them as custom elements: isCustomElement: (tag) => tag.startsWith("glass-"). The wrapper components do not need that. Named slots are <template #trigger>, #icon, #trailing, and #shortcut, not the HTML slot attribute. The menu sample on the Components page shows #trigger.

Next.js and server rendering

The React entry (glassy-liquid/react) is a Client Component: the file starts with "use client". In the Next.js App Router, import GlassScene, GlassButton, and GlassSwitch from a Client Component. The hello world above already has that directive.

The React, Vue, and Svelte bindings render defer-hydration on each element and remove it after hydration. While the attribute is present the element stays inert, so server markup matches the hydrated tree.

Every entry point is safe to import on the server. Custom elements register only in the browser, where customElements exists, so importing glassy-liquid, glassy-liquid/elements, or a component module from code the server evaluates does not throw. glass(), useGlass(), and attachPress() touch the DOM, so call them in an effect or in onMount, as the playground snippets do.

Scenes

Safari drops SVG filters inside backdrop-filter, so it cannot bend arbitrary page content. A scene tells the glass what is behind it: an image, a video, a canvas, or a DOM layer. Chromium keeps the faster backdrop path unless the scene sets force.

scene.html
<!-- Photograph or video: WebGL, GPU only. src is any image URL. -->
<glass-scene src="https://upload.wikimedia.org/wikipedia/commons/thumb/5/58/Iceberg_reflection_in_J%C3%B6kuls%C3%A1rl%C3%B3n_%28Unsplash%29.jpg/960px-Iceberg_reflection_in_J%C3%B6kuls%C3%A1rl%C3%B3n_%28Unsplash%29.jpg" style="background: linear-gradient(160deg, #9bb7c9, #e7eef2)">…glass…</glass-scene>

<!-- Live DOM: one scoped content filter -->
<glass-scene>
  <article glass-backdrop>…your content…</article>
  <glass-surface radius="capsule"></glass-surface>
</glass-scene>

glass()

glass(element, options) turns your own markup into Liquid Glass and returns a controller. The lens on the home page is built this way. The playground prints a ready-to-paste call.

lens.js
import { glass, attachPress } from "glassy-liquid";

const lens = document.querySelector(".lens");
const surface = glass(lens, {
  radius: "circle",
  material: "clear",
  zoom: 1.18,
  refraction: 30,
});
attachPress(lens, surface);

surface.set({ tint: "#0a84ff" });
surface.engine;   // "backdrop" | "scene-gl" | "scene-dom" | "css"
surface.destroy();
OptionTypeDefaultWhat it does

React, Vue, and Svelte expose the same options through useGlass. On a custom element, the same names are attributes, except zoom, backdrop, and fill, which exist only on glass(). In HTML the angle is light-angle. interactive is not a glass option. It is a component flag that turns on the press response (attachPress).
